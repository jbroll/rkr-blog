# rkr-blog marketing website

Static landing page for rkr-blog, served at `rkr-blog-www.rkroll.com`. Part
of the rkroll family of sibling sites (`checklist`, `drop-notes`,
`wicketmap`). The blog application itself is a separate deploy
(`../deploy.conf`, `roll-along.rkroll.com`) and is not affected by anything
here.

## Contents

Only `public/` is deployed to the web root; everything else stays private.

- `public/index.html` — landing page (hero + feature grid), hand-authored
- `public/about.html` / `public/privacy.html` / `public/terms.html` —
  generated by `build-legal.js`; do not edit by hand
- `public/rkr-blog-icon.svg` — nav logo / favicon
- `about.md` / `privacy.md` / `terms.md` — legal page **sources**; edit
  these, then regenerate
- `build-legal.js` — markdown → HTML generator (writes into `public/`)
- `deploy.conf` — static-mode Apache deploy config (kept out of the web root)

## Editing legal pages

```bash
# 1. edit the markdown source (about.md / privacy.md / terms.md)
# 2. regenerate the HTML:
node website/build-legal.js
```

## Preview

```bash
open website/index.html       # or: xdg-open website/index.html
```

Pure static files — Tailwind loads from its CDN, so no build or server is
needed to preview.

## Deploy

```bash
deploy.sh init   website/     # first time: SSL cert + Apache vhost
deploy.sh update website/     # subsequent: copy static files
```

DNS for `rkr-blog-www.rkroll.com` must resolve to the VPS before `init`.
