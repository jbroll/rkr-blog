# image-pwa Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract the blog's image-edit logic into a shared npm-workspace package (`@rkr/image-edit`) and build a standalone `apps/image-pwa` PWA that uploads, edits (full parity: crop/rotate/tilt/flip/perspective/resample), and downloads images.

**Architecture:** One package, two subpath exports — `@rkr/image-edit` (isomorphic core: types, validation, ops-state, math, constants, canonical-json) and `@rkr/image-edit/canvas` (browser-only: pixel pipeline, encode helpers, injected-source cropper/perspective modals, ingest-resize). The package builds to `dist/` JS+`.d.ts` because Node 22 `--experimental-strip-types` won't strip types under `node_modules`, and the strip-types server imports the core at runtime. The blog re-points its imports to the package; the PWA consumes both exports with app-local UI glue.

**Tech Stack:** Node 22, TypeScript (nodenext + bundler), esbuild, cropperjs, npm workspaces, c8, Playwright, lefthook/org-hooks.

**Discovered coupling (drives the design):**
- `image-edit-ops` → `canonical-json` (also used by `hash.ts`, `sidecar-base.ts`) → moves to core; those two re-point.
- `canvas-loaders.ts` mixes pure encode helpers (move), id/OPFS `loadOriginal`/`getPipelineCache` (stay in blog), and TipTap preview wiring (stay in blog).
- The two modals reach for `getPipelineCache`/`loadOriginal`/`webpOrJpeg` (canvas-loaders), `$`/`setStatus` (dom→toast), `openModal` (dialog-focus). In the package they instead receive a decoded `CanvasSource` + an optional `onStatus` callback, and use a package-local `$`/`openModal`. No blog UI deps cross the boundary.

**Staging — each stage leaves the repo green (full lefthook gauntlet) and is independently shippable:**
- Stage 0: workspace scaffolding (empty package + app skeletons, root scripts, knip map, lefthook ws-awareness).
- Stage 1: move CORE (7 pure files) into the package; re-point all blog/test imports; verify server runtime imports built core JS.
- Stage 2: move canvas pipeline + encode helpers + the two modals (injected-source) into the package; re-point blog.
- Stage 3: build `apps/image-pwa`.

**Conventions for every task:** run `npm run typecheck` and the relevant tests before each commit. Commit messages end with the repo's `Co-Authored-By` trailer. Work on branch `feat/image-pwa-extraction`.

export function canvasToBlob(
  canvas: HTMLCanvasElement,
  type: string,
  quality?: number,
): Promise<Blob> {
  return new Promise((resolve, reject) => {
    canvas.toBlob(
      (blob) => (blob ? resolve(blob) : reject(new Error('toBlob returned null'))),
      type,
      quality,
    );
  });
}

export const supportsWebP: boolean = (() => {
  const c = document.createElement('canvas');
  c.width = 1;
  c.height = 1;
  return c.toDataURL('image/webp').startsWith('data:image/webp');
})();

export function webpOrJpeg(canvas: HTMLCanvasElement, quality = 0.95): Promise<Blob> {
  return canvasToBlob(canvas, supportsWebP ? 'image/webp' : 'image/jpeg', quality);
}

import {
  type LocalEditState,
  appendRotate,
  appendFlip,
  localUndo,
  localRedo,
  localMutate,
} from '@rkr/image-edit';

export interface MemoryState {
  state: LocalEditState;
  onChange: () => void;
}

export function createMemoryState(width: number, height: number): MemoryState {
  return {
    state: {
      ops: [],
      redoStack: [],
      baseline: { ops: [], redoStack: [] },
      sourceWidth: width,
      sourceHeight: height,
    },
    onChange: () => {},
  };
}

export function applyRotate(s: MemoryState, degrees: number): void {
  s.state.ops = appendRotate(s.state.ops, degrees);
  s.state.redoStack = [];
  s.onChange();
}

export function applyFlip(s: MemoryState, axis: 'horizontal' | 'vertical'): void {
  s.state.ops = appendFlip(s.state.ops, axis);
  s.state.redoStack = [];
  s.onChange();
}

export function canUndo(s: MemoryState): boolean {
  return s.state.ops.length > 0;
}

export function canRedo(s: MemoryState): boolean {
  return s.state.redoStack.length > 0;
}

export function undo(s: MemoryState): void {
  localUndo(s.state);
  s.onChange();
}

export function redo(s: MemoryState): void {
  localRedo(s.state);
  s.onChange();
}
```

export type OutFormat = 'png' | 'webp' | 'jpeg';

export function mimeFor(fmt: OutFormat): string {
  return fmt === 'png' ? 'image/png' : fmt === 'webp' ? 'image/webp' : 'image/jpeg';
}

export function outputName(inputName: string, fmt: OutFormat): string {
  const dot = inputName.lastIndexOf('.');
  const stem = dot > 0 ? inputName.slice(0, dot) : inputName;
  return `${stem}-edited.${fmt}`;
}

// Browser-only: encode a canvas and trigger a download.
export async function downloadCanvas(
  canvas: HTMLCanvasElement,
  inputName: string,
  fmt: OutFormat,
  quality: number,
): Promise<void> {
  const blob = await new Promise<Blob>((resolve, reject) =>
    canvas.toBlob(
      (b) => (b ? resolve(b) : reject(new Error('toBlob null'))),
      mimeFor(fmt),
      fmt === 'png' ? undefined : quality,
    ),
  );
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = outputName(inputName, fmt);
  a.click();
  URL.revokeObjectURL(url);
}
```
