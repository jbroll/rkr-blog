# Organizational Sites Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the 20 remaining gaps the ECCG trial port found, so a co-op can run a pages-first site on rkr-blog with no per-site code and no theme hacks.

**Architecture:** Pages gain a `kind` and a configurable home page; macros gain list slots, quiet empty leaves and a class hook; grid bands gain tokens, background images, alignment and panels; the header and footer come from settings and a `_footer` system page; small blocks get palette entries and dialogs; seed macros and site-root themes ship last. Each part lands as one or more commits, each behind the repo gate.

**Tech Stack:** Node 22 + TypeScript (strip-types), Fastify, node:sqlite, remark, esbuild browser bundles, node:test, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-27-org-site-design.md`. Executors read the spec section named in each task before starting.

## Global Constraints

- Production source under `src/` and `bin/` stays under 500 lines per file (tests exempt). Files already close: `src/lib/config.ts` (448), `src/routes/public.ts` (469), `src/widgets/figure.ts` (382), `src/admin/figure-dialog-tree.ts` (385). Each task names the new file that takes the growth.
- Conventions in `docs/developer-quickstart.md §4`: ES modules, `.ts` import extensions on the server, extensionless in `src/admin`/`src/site`, kebab-case files, named exports, no top-level side effects.
- Tests: `node:test` + `node:assert/strict`, mirror `src/` under `test/`. Browser dialog tests use `test/admin/fake-dom.ts`. Run one file with `node --no-warnings=ExperimentalWarning --experimental-strip-types --test test/<path>.test.ts` (or `npm test -- test/<path>`, whichever the repo's `package.json` `test` script accepts).
- Commit gate is lefthook (biome, tsc, knip, circular, size, coverage, CI dispatch). Never `--no-verify`. CI tests the working tree, so stage everything the commit needs.
- Every new public class or token goes into `docs/theming.md` in the same commit. Behavior changes go into `docs/spec.md` (§8 content model, §8a blocks, §11 routes, §14a header) in the same commit. Deferred work goes in `docs/DEFERRED.md`, one line, with a `_revisit when:_`.
- Existing sites are unaffected: absent `fields.kind` means `post`, absent `homePage` keeps `/`, absent `menu` keeps the current header, absent `_footer` keeps the current footer, absent site `themes/` keeps the repo theme list.
- Authors never type class names, raw colors or raw CSS. Every new author-facing option is a select, checkbox, picker or plain text.
- Slug and theme names stay `[a-z0-9-]+` (theme names `^[a-z][a-z0-9-]*$`). All author links go through `safeLinkUrl` (`src/lib/safe-url.ts`).
- Embed allowlist, exactly: `docs.google.com`, `www.youtube-nocookie.com`, `player.vimeo.com`, and `www.google.com` only for paths under `/maps/embed`.
- Social platforms, exactly: `facebook`, `instagram`, `youtube`, `mastodon`, `bluesky`, `email`.
- Section theme built-ins, exactly: `light`, `light-bold`, `dark`, `dark-bold`. Tokens `--rkr-section-<name>-bg`, `-fg`, `-heading`, `-link`; `--rkr-section-pad`; `--rkr-box-bg`, `--rkr-box-fg`, `--rkr-box-pad`, `--rkr-radius`.

## Review Focus

1. **Home page set to a draft or deleted page.** Everyone at `/` gets the post index, and `/<slug>` of that draft does not 301. Pinned in Task 2.
2. **A comment POSTed to a `kind: page` slug** (form still cached, or a scripted client). It is refused with 404 and nothing is stored. Pinned in Task 1.
3. **A list slot item with an image id inside an `each` grid** renders the picture publicly, not an unresolved-id comment (the class of bug `f438157` fixed). Pinned in Task 3.
4. **A macro edited with the list dialog, then the dialog reopened** shows the saved rows, and clearing every row falls back to the macro default rather than storing `[]` forever. Pinned in Task 4.
5. **An embed URL on an allowed host but a disallowed path** (`www.google.com/search?q=…`) renders as a plain link, and the CSP never allows it as a frame. Pinned in Task 10.
